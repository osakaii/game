# Changelog

Все заметные изменения игры. Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версии — [SemVer](https://semver.org/lang/ru/).

Как вести: новые изменения пиши в раздел **[Unreleased]**. При выпуске `pnpm release <major|minor|patch>`
перенесёт их под номер новой версии.

## [Unreleased]

### Добавлено
- Палитра в Мастерской: квадрат насыщенности/яркости, оттенки, плотность краски, ввод #hex, сохранённые цвета, сравнение цвета кисти с цветом фона.

### Изменено
- Покраска: вместо 6 зон — свободная кисть в «Мастерской» (облёт камерой, жесты, мазок без швов через рёбра, отмена/повтор, пипетка по себе и по миру).
- Кожа персонажа передаётся другим игрокам картинкой после паузы в покраске; новички и вернувшиеся получают её сразу.
- Время пряток по умолчанию — 60 с (варианты 40/60/90).

### Удалено
- Покраска по зонам тела.

## [1.0.0] — 2026-10-14

Первый релиз.

### Игра
- Мультиплеерные прятки до 8 игроков: лобби, комнаты по коду, ссылки-приглашения.
- Фазы раунда: прятки → поиск → итоги, роли раздаются по честной очереди.
- Покраска себя: пипетка по предметам, 6 зон тела.
- Поиск тапом с проверкой на сервере, следы краски на поверхностях.
- Присед (можно залезть под стол), найденные помогают искать или становятся призраками.
- Три карты: Детская, Кухня, Сад. Настройки комнаты для хоста, очки за раунды.

### Мобильные устройства
- Плавающий джойстик, управление камерой пальцем, PWA, полноэкранный режим, экран не гаснет.
- Синтезированные звуки, тени с переключателем, экран загрузки.

### Надёжность
- Переподключение с сохранением роли, защита от спама запросами.
- Сервер проверяет скорость, стены, гравитацию; компенсация задержки при поиске.
- Версия сборки в меню и в игре (HUD), предложение обновиться после нового деплоя.
