# @mecha/client — Vite + three.js, мобильный браузер

Без UI-фреймворка: DOM-разметка в `index.html`, классы-контроллеры в `src/ui/`, стили в `src/style.css` и по частям в `src/styles/` (`room.css`; большой `style.css` разбираем по мере переделки экранов, подключение — `import` в `main.ts` после `style.css`).
Точка сборки всего — `src/main.ts` (создаёт объекты, связывает события, игровой цикл). Dev-хук `window.__mecha`.

## Модули
| Папка | Ответственность |
|---|---|
| `core/` | `Emitter` (типизированный observer), `fixed-step-loop` (физика 60 Гц + рендер с интерполяцией), `perf-governor` (автокачество: тени → лёгкая краска + 1× разрешение, только вниз) |
| `net/` | `Network` (обёртка socket.io: запросы с таймаутом → `Result`, события), `ServerClock` (смещение часов по пингу), `StateSender` (своя позиция 20 Гц), `session-id` (секрет сессии в sessionStorage) |
| `lobby/` | `Lobby` (состояние комнаты, гонки room:state vs ack, переподключение), `invite` (?room=CODE, Web Share) |
| `world/` | `ShotFx` (вспышка, летящая капля, брызги-InstancedMesh; свой выстрел летит в предсказанную точку и доворачивает к серверной), `scene-setup` (renderer, свет, тени), `ActiveMap` (текущая карта; потребители читают живые `colliders/obstacles` через `WorldGeometry`), `map-builder` (форма → геометрия, UV в метрах мира «кубической» развёрткой, склейка по поверхности, цвет блока — в вершинах; детализация круглых деталей по размеру), `paintings` (холсты с `art`: процедурные сюжеты в общем атласе, UV на большую грань без зеркала), `surfaces` (процедурные текстуры массивом байтов — без canvas, пипетка читает пиксель; рисунок светлый, цвет блока тонирует), `RemotePlayers` (чужие игроки, кэш кож по ревизии), `splats` (пятна проверок) |
| `player/` | `PlayerModel` (SkinnedMesh на скелете из 14 костей + глаза; суставы — пружины к целевой позе; шаг, ползание, присед, прыжок, дыхание, манекен, призрак), `body-poses` (все позы как углы суставов: стойка, присед, прыжок, Мастерская, 6 поз пряток), `LocalPlayer` (физика из shared + интерполяция), `RemotePlayer` (интерполяция снимков, serverNow−100 мс), `name-label` |
| `camera/` | Камера от третьего лица (не уходит в стены) |
| `input/` | `Controls` (pointer events: джойстик слева, камера справа, тап; присед/прыжок; выбранная поза + `onPoseChange`), клавиатура (1–6 позы, 0/X встать) |
| `seek/` | `SeekerControls` — тап → луч из камеры → `seek:shoot` (+`viewTime`), события `fire`/`result`; `SeekerEffects` — ощущения выстрела (разворот, отдача, звук, вибрация, кольцо перезарядки, крестик, чужие выстрелы) |
| `skin/` | **Тело и кожа**: `character-parts` (скелет: размеры, скругления, плоские торцы `caps` у стыков конечностей, суставы; `JOINT_LINKS` — суставы с мягкой привязкой; `restJoint/restCenter`, `paintMask`, `mirrorPart`), `rounded-box` (плоская грань → скруглённая поверхность), `body-geometry` (всё тело одной геометрией в позе покоя; `boneWeights` — у локтя/колена вершины на двух костях, skinIndex[0] — всегда своя часть), `atlas` (UV-атлас 512², плотность одинакова, side faces: «вверх текстуры» = вверх мира), `position-map` (тексель → точка в позе покоя + нормаль), `skin-texture` (canvas-кожа: основа/картинка из сети) |
| `paint/` | **Покраска своего персонажа** — см. ниже |
| `painting/eyedropper.ts` | Пипетка по миру: цвет МАТЕРИАЛА под лучом (не освещённый пиксель) |
| `ui/` | `PoseWheel` (колесо поз), HUD (тихий для игрока, подробный в dev), меню, `RoomPanel` (плашка «КОД · 2/8» + шторка справа, закрывается при смене фазы), `LobbyBar` (главное действие лобби по центру сверху), `ConfirmDialog` (`ask()` → Promise, вместо `window.confirm`), настройки, фазы/итоги, палитра, панель Мастерской, тосты, баннер обновления |
| `audio/` | `Sfx` (Web Audio синтез, без файлов), `GameSounds` (когда что играть — тестируемо) |
| `platform/` | Fullscreen, Wake Lock, подсказка поворота, настройки графики (тени) |

## Конвейер покраски (`src/paint/`)
```
PaintStudio (жесты, луч в SkinnedMesh → барицентрика → точка и нормаль в ПОЗЕ ПОКОЯ)
  → brush-stamps (оттиски вдоль мазка)
  → SkinPainter.stamp → МОКРЫЙ слой (wet ping-pong, half-float)
  → update() 30 Гц, пока мокро: flow ×2 (растекание, подтёки) → сушка в СУХОЙ слой → composite в VIEW
  → VIEW натянут на модель; из него снимки undo, readColor, exportImage
SkinSync: после паузы и высыхания → WebP → network.uploadSkin → сервер → остальные (RemotePlayers.setSkinImage)
```
- Шейдеры — `wet-shaders.ts` (комментарии к каждому). Смешивание красок — среднее геометрическое (вычитательное), НЕ OKLab; OKLab — только для сравнения цветов в палитре (`color.ts`).
- Устойчивость течения: `4 × uDiffusion × 1.65 < 1`. Видимость краски `coverage(a)=a/0.6`, не равна количеству.
- Основа кожи (`setBase`) рисуется локально; сервер сбрасывает кожу ревизией без картинки (начало раунда, помощник).
- `PaintStudio.edited` → `SkinSync` (отправка), `change` → UI, `stroke` → шорох кисти (`Sfx.brush`). Палитра держит HSV (не терять оттенок у серых).
- Поза покоя (стоит, руки вниз, суставы не повёрнуты) — общая система координат кисти: вершины геометрии и карта позиций в ней, поэтому кисть работает в любой позе. Оттиск красит свою часть + соседей по суставу, если рядом с суставом (`paintMask`, битовая маска `uMasks` в шейдере) — рука вдоль торса краску с бока торса не получает.
- Новая часть тела/размер: правишь только `character-parts.ts` (+ `BODY_ZONES` в shared, протокол++); атлас, геометрия, карта позиций строятся сами, тесты сверяют их между собой.
- Инструменты = режимы одного шейдера кисти (`uMode`: кисть/спрей/губка/ластик). Ластик кладёт цвет основы части (`setBaseColors`). Симметрия зеркалит оттиски по X в позе покоя с заменой левых/правых частей (`mirrorPart`). «Глазами ищущего» — `StudioCamera.preview` (6.5 м, кисть выключена).

## Позы
- Поза = выбор игрока (`controls.pose`) → `MoveInput.pose` → `stepPlayer` решает, принять ли (на земле, над головой свободно) → `state.pose` → сеть (`PlayerState.pose`) → чужие модели.
- Лазание: `state.climbing`/`wallNormal` из физики → модель смотрит в стену (`LocalPlayer.render`), поза `CLIMB` + `addClimb`; у чужих — `PlayerState.climbing`.
- Поза «на месте» снята движением — `main.ts` сбрасывает и выбор (`cancelsPose`), иначе персонаж снова лёг бы при остановке.
- Новая поза: id в `POSES` + правило в `POSE_RULES` (shared) → углы в `POSE_LIBRARY` → подпись/значок в `POSE_LABELS` → `pnpm hitboxes`. Оси суставов описаны в `body-poses.ts`.
- Хитбоксы: `test/player/pose-hitboxes.test.ts` меряет модель (`holdStance` — без пружин и дыхания, детерминированно) и сверяет с `shared/src/pose-hitboxes.ts` через `toMatchFileSnapshot`. Dev-клавиша H — `hitbox-debug.ts`.

## Карта
- Шоурум всей мебели для проверки глазами (dev-консоль): `const s = await import('/@id/@mecha/shared')`, собрать `props` из `s.PROP_IDS` сеткой и `__mecha.followCamera.world.load({...MapDef})`.
- Пипетка: цвет вершины блока × пиксель рисунка в точке (`surfaceColor`). Материалы карты белые с `vertexColors`; `glow` и потолок — `MeshBasicMaterial` (без освещения).

## Выстрел
- Отклик сразу по тапу (предсказание), итог — от сервера: `seek:shot` подтверждает свои капли по порядку (`ShotFx.confirmOwn`), отказ ack → `cancelOwn` (капля пшикает). Пятно/звук/«найден» — в `onImpact`, когда капля долетела.
- Краскомёт (`player/blaster.ts`) висит на кости `handRight`; рука держит его в `PlayerModel.holdBlaster`, отдача — толчок скорости пружин (`fire`). Цвет краски ищущих — `SEEKER_PAINT`.

## Подводные камни
- CSS: браузер молча глотает незакрытую `}` — всё ниже становится частью блока (так `@media (pointer: fine)` однажды съел 60% стилей телефона). `test/style.test.ts` проверяет баланс скобок и что раздел `/* ---------- X ---------- */` не начинается внутри блока. Общие размеры — переменные в `:root` (`--edge-*` с safe area, `--touch`), низкий экран — `@media (max-height: 500px)`.
- Перед `canvas.toDataURL()`/`readPixels` рисуй кадр в том же синхронном коде.
- `SkinTexture` без `document` (тесты в Node) не рисует — это нормально.
- Тени запечены (`shadowMap.autoUpdate = false`): после смены карты/включения теней — `refreshShadows`. Персонажи тень не отбрасывают (круглая тень), но получают.
- Меняешь форму тела (`character-parts`) — `pnpm hitboxes`, иначе упадёт тест хитбоксов.
- У `SkinnedMesh` границы (boundingBox/Sphere) заданы вручную с запасом на любые позы: сами они не пересчитываются, и луч кисти «терял» бы вытянутую руку.
- Удаляемые меши/материалы/рендер-таргеты — `dispose()` (видеопамять не освобождается сама).
- `Controls.enabled=false` (меню, Мастерская, ослеплённый ищущий) — тогда касания холста принадлежат Мастерской.
